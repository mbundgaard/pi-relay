# Changelog

## 0.1.1

- Publish as `@comput/pi-relay` under the MIT license.
- Known limitation: automatic replies to expired peer tunnels can still emit repeated errors.

- Prepare npm package metadata and an explicit tarball file allowlist.

- One-to-one relay tools and slash commands for Pi.
- Automatic Cloudflare Quick Tunnel startup and compact pairing links.
- Bearer-authenticated messaging and expiring pairing codes.
- Automatic assistant replies delivered as remote notifications.
